# GGC_QA_001 — Test Plan

## Objective
Validate the Genoa Golf Club demo redesign against functional, responsive, API and database requirements.

## Scope
Home, navigation, tee-time CTA, venue enquiry form, events, popup, REST APIs, MongoDB persistence, responsive behavior and release smoke testing.

## Test Types
- Functional testing
- Responsive/browser testing
- API testing with Postman
- Database validation
- Regression testing
- Selenium smoke automation
- UAT/release validation

## Environments
- Local React frontend
- Local Node/Express API
- Local MongoDB or MongoDB Atlas test database

## Entry Criteria
Application starts successfully and the test database is available.

## Exit Criteria
Critical paths pass, no unresolved critical defects, and test evidence is captured.
